# Escenario de calidad (plantilla)

Un atributo de calidad ("rendimiento", "disponibilidad") sin número no se puede comprobar. Un **escenario** lo vuelve medible.

| Parte | Pregunta | Ejemplo (SaludYa) |
| --- | --- | --- |
| Quién o qué lo provoca | ¿Quién hace algo o qué ocurre? | Un paciente desde el celular |
| Estímulo | ¿Qué hace? | Pide una cita un lunes a las 8:00 |
| Condición | ¿En qué situación? | Hay 500 pacientes pidiendo citas a la vez |
| Respuesta | ¿Qué debe hacer el sistema? | Confirma la cita |
| Medida | ¿Cómo sabremos que está bien? | En menos de 3 segundos para el 95 % de las peticiones |

**Frase lista:** «Cuando _[quién]_ _[estímulo]_ _[condición]_, el sistema _[respuesta]_ _[medida]_.»

Regla práctica: si la medida no lleva un número, una cantidad o un tiempo, todavía es un deseo.
